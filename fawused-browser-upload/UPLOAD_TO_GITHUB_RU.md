# Как загрузить FAWUsed в GitHub через браузер

1. Создайте пустой приватный репозиторий `fawused` на GitHub.
2. Откройте его и нажмите **Add file → Upload files**.
3. Распакуйте архив `fawused-browser-upload.zip` на компьютере.
4. Перетащите в окно GitHub **всё содержимое** папки `fawused-browser-upload`.
5. Внизу напишите `Initial FAWUsed MVP` и нажмите **Commit changes**.

Важно: не загружайте сам ZIP. Загружайте файлы и папки из распакованной папки.
